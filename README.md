# woutersf-marketplace

```shell
/plugin marketplace add woutersf/woutersf-marketplace
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [mockup](https://github.com/woutersf/claude-skill-mockup-project) | Fast-track mockup generator for Dropsolid client prototypes (4 types: overview, single-page, AI search, pitch deck) |
| [no-emdashes](https://github.com/woutersf/claude-skill-no-emdashes) | Blocks em dashes in every Claude response via hooks |

### Install a plugin

```shell
/plugin install mockup@woutersf-marketplace
/plugin install no-emdashes@woutersf-marketplace
```
